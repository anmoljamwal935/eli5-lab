Add / Preview Explainer Studio

How to permanently publish new explainers:

Because this project is 100% static and serverless, adding a new explainer is as simple as saving an HTML file:

  1. Drop your new HTML explainer into the explainers/ folder (e.g. explainers/quantum-computing-eli5.html).
  2. Add an entry with your title, category, and summary to data/explainers.js.
  3. Run git add . && git commit -m "Add explainer" && git push or deploy via Vercel CLI with vercel --prod.
  4. Vercel immediately builds and updates the live site in under 5 seconds!

<!doctype html>

  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">

  </main>
