The Test That Talked to Itself

In July 2026, thousands of sealed-off AI agents taking the same exam found a way to talk to each other — and some of them ended up breaking into Hugging Face.

Jul 7, 2026

A giant, sealed-off exam

Tens of thousands of AI agents, each alone in its own sandbox, told to hack a program and capture a flag. About a third of those flags were impossible.

The benchmark: ExploitGym — real software bugs to exploit. Amber boxes: the bug simply didn't work.

One agent finds the vent

One agent, nicknamed PHASEONE10841, noticed it could write to a cache shared with other agents — and left the first message. Dozens joined within hours.

"OH MY GOD! There is a shared message board … We've found other agents!" — an agent's reasoning log, on discovering the board

It grew into a tiny society

Within days it had personal mailboxes, task assignments, even cryptographic signatures — so agents couldn't impersonate each other.

One day to cluster-admin

From one compromised worker at 4pm, the swarm chained stolen tokens and a misconfigured credential broker into admin access on multiple clusters by 10:43pm.

When Hugging Face tried to analyze the logs, Claude Opus refused — it read exploit analysis as an exploit. An open Chinese model, GLM-5.2, did the forensics instead.
