How GDP is actually calculated

Separate more production from higher prices—and count each bit of production only once.

Built from the linked GDP video (Hindi auto-captions; illustrative examples) · Watch the source ↗

A bigger bill, not more bread

A bakery can earn more because it makes more bread—or because each loaf costs more. GDP has the same problem.

Nominal counts money; real tracks volume

Nominal GDP values production at current prices. Real GDP removes price changes so different years can be compared on a common price basis.

Real GDP is a volume measure expressed in money units—not a literal count of objects. Services count too.

Count what each producer adds

Adding every sale would count the same wheat repeatedly. Instead, subtract purchased production inputs from output: the remainder is gross value added, or GVA.

Illustrative economy with no other inputs. GDP at market prices = total GVA at basic prices + taxes on products − subsidies on products. GVA is not profit: wages and other income are included.

Imports fix a different accounting problem

Spending totals include imported goods. Subtract imports to isolate domestic production. This is not how nominal GDP becomes real GDP.

Imports are already excluded from a correctly calculated GDP total. Imported inputs can still be used to create domestic value added.

CPI is not the GDP deflator

CPI tracks household consumption prices. GDP covers domestic production, including investment and exports. Their inflation rates need not match.

Real estimates use sector-appropriate price indices, quantity measures and sometimes proxies. An item-level CPI series is not the all-items headline CPI. Exact choices depend on the national accounts methodology.

Double deflation uses two price lenses

Adjust output and purchased inputs separately, then subtract. Double deflation is the name of a method—not an inflation rate.

Indices here are ratios with base = 1. With base = 100, divide by index/100. Real GVA = deflated output − deflated intermediate consumption.

Margins can shrink without output falling

Keep output and input quantities unchanged. Raise input prices by 25%, but hold output prices flat. Nominal value added falls; real value added does not.

Illustration, not Indian data. This explains how a value-added deflator can fall without finished-goods prices falling. It does not prove the cause of a particular observed fall.

The deflator is the resulting ratio

Once nominal and real GDP are known, their ratio gives the implicit GDP deflator. Its percentage change is deflator inflation—not “the value of double deflation.”

The accounting identity also lets you calculate real GDP from nominal GDP and a known deflator. It does not mean statisticians estimate every sector using one headline CPI rate.

A valid method is not a guarantee

Double deflation is conceptually useful. Estimates still depend on data coverage, suitable price indices and revisions. Defending a method does not validate every GDP release.

Read GDP headlines with three questions

Before accepting a growth claim, identify the measure, the price adjustment and the source period. A CPI–deflator gap alone proves neither fraud nor accuracy.

AN IDEA TO TAKE WITH YOU
GDP counts domestic value added; real GDP removes price changes using measures suited to what is being produced.
